# Memory

Notas opcionales del equipo para agentes (decisiones, recordatorios, contexto de negocio).

- Preferir **rules** y **skills** para convenciones durables.
- Aquí solo lo que aún no merece una rule/skill formal.
- No guardar secretos, tokens ni datos personales.

Ejemplo de archivo: `decisions.md`, `glossary.md`.
